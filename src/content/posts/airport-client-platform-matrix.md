搜索“Windows 机场”“Mac 机场”“Android 机场”“iOS 机场”或“Clash 机场”时，用户真正需要的是兼容相应系统的机场订阅和客户端。机场提供订阅，客户端负责导入、分流和建立连接，两者不能混为一谈。

## Windows 机场客户端

机场 Windows 客户端常见选择包括 Clash Verge、v2rayN 和基于 sing-box 的工具。Clash for Windows 机场仍是常见搜索词，但原项目已停止维护时，不应从陌生下载站获取旧安装包。优先选择仍有清晰发布来源和安全更新的客户端。

- **Clash Verge 机场**：适合需要策略组、规则分流和图形界面的用户；
- **Clash Meta 机场**：通常指兼容相应内核或配置格式的订阅；
- **v2rayN 机场**：适合 V2Ray/Xray 生态配置管理；
- **sing-box 机场**：需要确认订阅格式、内核能力和客户端实现。

## Mac 机场客户端

机场 Mac 客户端应重点检查系统代理恢复、睡眠唤醒、Apple Silicon 兼容和自动更新来源。可选择支持 macOS 的 Clash Verge、sing-box 客户端或服务商明确推荐的软件。不要仅因 Windows 版本能用，就假设 Mac 版本配置完全一致。

## Android 机场客户端

机场安卓客户端常见有 v2rayNG、Clash Meta 兼容客户端和 sing-box 工具。v2rayNG 机场订阅是否可用，取决于协议与订阅格式。Android 还可能支持按应用分流，但省电策略会影响后台连接，需要把可信客户端加入合理的后台白名单。

## iOS 机场客户端

机场 iPhone 客户端常见有 Shadowrocket、Quantumult X 和 Stash。它们通常需要从合法应用商店获得，并遵守所在地区商店政策。

- **Shadowrocket 机场 / 小火箭机场**：关注订阅格式、规则和证书提示；
- **Quantumult X 机场**：关注配置语法、远程资源与策略；
- **Stash 机场**：关注 Clash 配置兼容和规则来源。

| 平台 | 常见搜索词 | 优先检查 |
| --- | --- | --- |

## 不要把“支持全平台”当成结论

购买前查看服务商是否分别提供各平台教程，而不是只有一张“全平台支持”图片。多平台使用还要确认设备数和并发限制。订阅链接属于敏感凭证，不要在公共转换网站或来历不明的客户端中导入。
